手机连不上电脑共享代理？局域网地址、监听端口与防火墙排查

小六2026-10-09— 次阅读
机场指南

电脑自己能用机场客户端，手机却连不上它共享的代理，先检查手机能否到达电脑的代理入口，再查远端节点。常见问题是地址填成了手机自己的 127.0.0.1、电脑只监听本机，或局域网访问被防火墙拦住。开启“允许局域网”只是其中一环。

作者：小六｜资料核对日期：2026年10月9日。本文以 Windows 电脑和 Mihomo 内核客户端的常见固定代理端口为例，适用于自己的家庭局域网，以及支持手动 HTTP 或 SOCKS 代理的应用。

一、手机里要填电脑地址，不是本机回环地址

电脑上的 127.0.0.1 指向电脑自己；同一个地址填进手机，指向的就是手机。其他设备访问电脑代理时，需要使用电脑当前可达的局域网地址。

Windows 可以运行查看命令：

ipconfig

找到实际连接家庭网络的 Wi-Fi 或以太网接口，核对其 IPv4 地址，不要把虚拟网卡地址当成共享入口。命令作用见微软 ipconfig 说明。

比如电脑当前地址是 192.168.1.20，代理端口是 7890，支持相应代理协议的应用就应分别填写这个地址和端口。两者都是示例，必须换成实际值；重连网络后，电脑地址也需要重新确认。

二、确认端口接收的是哪种协议

Mihomo 区分 HTTP、SOCKS 与混合入口。混合端口可接受 HTTP 和 SOCKS5，但具体端口号取决于生效配置。见官方代理端口文档。

对方应用的设置 应核对的入口
HTTP 代理 HTTP 或支持 HTTP 的混合端口
SOCKS5 代理 SOCKS 或支持 SOCKS5 的混合端口
只填写一个网页地址 不代表已配置代理协议与端口

不要把订阅链接、远程节点地址或客户端管理面板端口当成代理入口。手机浏览器能通过代理打开页面，也不能证明所有应用都采用了同一个设置；应核对实际使用的软件是否支持该代理方式。

三、打开共享后，检查是否真的监听局域网

Mihomo 的 allow-lan 允许其他设备经过本机代理端口访问，bind-address 决定绑定地址；允许、禁止的来源 IP 范围也会影响访问。相关字段见全局配置文档。

先通过所用客户端支持的入口核对生效配置。开关显示已开启，不一定能解释最终监听状态。在 Windows PowerShell 中，可查询一个实际端口：

Get-NetTCPConnection -State Listen -LocalPort 7890 |
  Select-Object LocalAddress, LocalPort, OwningProcess

把 7890 换成实际入口。命令用于查看 TCP 状态与地址，依据是微软 Get-NetTCPConnection 文档。没有结果时，先查客户端是否运行、端口是否正确；不要先修改路由器。

如果只监听 127.0.0.1，其他设备不能把它当成局域网入口。监听电脑的局域网地址或所有 IPv4 接口，也只是满足一项条件，仍需核对访问范围和防火墙。若有端口冲突，可参考本站Windows 监听端口排查。

四、同一个 Wi-Fi 名称，不代表一定互通

先确认两台设备使用的是自己的主网络，而非访客网络。路由器的访客隔离、设备隔离或不同网段之间的路由安排，都可能影响设备互访，应按对应路由器的说明核对。

再检查 Windows 入站规则。微软的防火墙配置说明介绍了程序、协议、端口、来源地址范围与网络配置文件的限制方式。

家庭共享应围绕实际客户端程序和代理端口核对规则，限定所需设备来源及适用网络；不要用关闭整个防火墙代替排查，也不要为了共享代理随意把不可信网络改成专用网络。管理设备上的规则应由管理员确认。

五、根据结果判断下一步

观察结果 下一步
电脑自己访问也失败 先处理客户端或节点连接
电脑可用，手机请求没有进入客户端 地址、监听、隔离与入站规则
出现代理认证要求 核对所用应用能否提供正确凭据
手机请求已进入，但目标连接失败 实际规则、出口与目标报错

共享入口如果启用了用户验证，还需要对方应用支持相应认证。Mihomo 的代理认证与管理接口凭据是不同配置，不能混填；具体支持方式以应用说明为准。

只向需要的家庭设备开放入口，按需要限制来源并设置认证。不需要路由器公网端口转发；不再共享时，撤销共享设置及专门添加的规则。公开求助也无需提供认证信息。

常见问题

电脑开了 TUN，手机是不是就自动走电脑节点？

不能这样推断。本文讨论手机显式连接电脑的代理端口，电脑自身的 TUN 接管不等于已给其他设备配置代理。应从手机发起一次明确使用该入口的新请求，查看电脑是否收到。

“允许局域网”能修好 NAS 访问吗？

这是另一个方向。手机连接电脑代理是共享入口；电脑访问 NAS 涉及本地目标的分流和路由，可阅读本站局域网设备访问排查。
